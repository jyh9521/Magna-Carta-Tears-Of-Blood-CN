# 全46部动画播放结束故障核查

日期：2026-10-12。目标是当前测试镜像，不是此前不同字体/菜单版本。

## 结论与证据等级

**Verified：25部汉化动画全部缺少MPEG视频流结束码`00 00 01 B7`；23部存在FFprobe解复用视频DTS倒退，其中18部在原始PES头中就有显式DTS倒退。** 另外21部影片与原ISO逐字节一致。

用户已验证：同一动画前即时存档，其他汉化不变，只把180111恢复为原影片的对照镜像能正常结束并进入后续流程。这将故障定位到替换SFD/播放器交互，不再归因于即时存档。它尚未区分B7、时间戳、视频编码或其他SFD差异哪一项单独导致卡死，也不证明另外24部已经游戏内复现。

**High-confidence deduction：缺失视频sequence_end_code是当前最直接的共同结束逻辑风险。** 原影片均在视频ES末尾有B7，当前25部重编码影片均没有；46部容器末尾均有B9。B9是program_end_code，不是B7，不能用B9存在替代视频结束检查。

**Verified：本地sfd-muxer 0.1.1的`_parse_picture`错误读取10位temporal_reference。** 实际表达式为`(byte4 >> 6) | (byte5 >> 6)`，正确位布局为`(byte4 << 2) | (byte5 >> 6)`。人工构造帧序号11：旧读法返回3，独立读法返回11。遍历0..1023，旧读法错误1020项，独立修正副本错误0项。对当前25部真实ES逐图片核查，共26915个帧序号被旧读法误读。

这项位布局依据：[RFC 2250 section 3.4](https://datatracker.ietf.org/doc/html/rfc2250#section-3.4)明确temporal-reference为10位。上游关系：Python包作者soyjxck；其注明移植自[nebulas-star/SFD_Muxer](https://github.com/nebulas-star/SFD_Muxer)。上述错误只对实际安装包作实证，不据此断言所有上游版本都有同样缺陷。

**Verified：只修帧序号位移还不够。** 隔离副本对180111保留现有中文字幕视频ES与ADX，重新封装后仍有1次显式DTS倒退、2次解复用DTS倒退。因此不把这一行修正称为完整修复，不覆盖游戏镜像或依赖包。
