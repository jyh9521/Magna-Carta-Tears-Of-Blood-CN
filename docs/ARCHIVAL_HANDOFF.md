## 本轮清理方式

已完成的独立源码/回滚验证副本与 Python 缓存先合并为 ZIP，逐项核对 SHA-256 后删除松散副本。原版、最终镜像、独有研究结果和现行构建输入不在删除清单。独立恢复验收已通过；本轮恢复验收目录仍保留在 `work/archive-readiness-20261022/recovery-test/`（318931271 字节），供交接复核。因此松散清理候选扣除 ZIP 的减少量不代表本轮项目整体净释放空间。

本地审计目录为 `work/archive-readiness-20261022/`：

- `MODIFIED_FILE.json`：逐项路径、大小、SHA-256、删除原因与恢复来源。
- `DIFF_FILE.json`：松散文件到压缩归档的变化清单。
- `retired-fixtures-and-caches.zip`：原字节无损备份，供精确恢复。
- `source-baseline.zip` 与 `source-baseline.json`：整理前实际工作区源码身份，包含当时未提交的有效改动，不包含完整游戏资源。
- `ROLLBACK.sh`：恢复到指定的全新独立目录，避免覆盖现行文件。
- `VERIFICATION.txt`：基线/整理后/独立恢复测试、退出码与 GitHub 同步结果。

这些本地审计产物不上传 GitHub，也不是正常工具运行所需的隐含输入。旧文档引用的松散验证目录已归档时，按清单从 ZIP 恢复；此前已退役的历史游戏资源仍按旧维护记录的恢复或重建规则处理。
